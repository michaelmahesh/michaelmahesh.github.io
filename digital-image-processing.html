Overview

Digital Image Processing Learning Path

The subject is organised as five modules and 50 numbered topics. Each numbered topic is organised around three student-focused resources: Notes, Python/OpenCV Code and Practice Questions.

Digital Image Processing develops the foundations required to represent, enhance, segment, analyse and compress digital images. The progression moves from pixels and color models through spatial and frequency-domain enhancement, segmentation, morphology and compression. Each numbered topic provides direct access to Notes, Python/OpenCV Code and Practice Questions.
