Course Roadmap

Deep Networks

Neurons, DNNs, activation functions, loss, optimization, backpropagation, regularization and batch normalization.

CNN

Convolution, pooling, stride, padding, architectures, CIFAR-10, transfer learning and augmentation.

View Unit →

RNN & LSTM

RNN topologies, training difficulties, bidirectional networks, LSTM, BiLSTM, GRU, embeddings and NER.

Unsupervised Learning

Applications

Digital Image Processing

Image Processing Roadmap

A five-unit progression from image fundamentals to compression and practical image analysis.

I

Image Fundamentals

Image acquisition, sampling, quantization, pixel relationships, RGB, HSI, DFT and DCT.

View Unit →
II

Image Enhancement

Gray transformations, histograms, spatial filtering, Fourier-domain filtering and color enhancement.

View Unit →
III

Image Segmentation

Edge detection, Hough transform, thresholding, region methods and watershed.

View Unit →
IV

Morphological Processing

Erosion, dilation, opening, closing, hit-or-miss, reconstruction and grayscale morphology.

View Unit →
V

Image Compression

Lossless and lossy compression, Huffman, RLE, arithmetic coding and JPEG.

View Unit →
