Deep Learning Learning Path

The subject is organised as modules and numbered topics. Hours, L/T/P information and formal unit tables are intentionally omitted.

Deep learning uses multilayer neural networks to learn representations directly from data. This page follows a progressive path from fundamental neural-network concepts to CNNs, sequence models, generative learning and real-world computer-vision applications. Each topic can later be connected to detailed notes, mathematical explanations, diagrams, Python examples, PyTorch notebooks, practical exercises and references.

Coding & Implementation

Python + PyTorch

The practical implementation layer for this subject uses Python and PyTorch. The examples below provide a starting point for topic-wise notebooks and experiments.

Python · Basic Neural Network

Foundation
import numpy as np

# Simple neuron computation
x = np.array([0.5, 0.8, 0.2])
w = np.array([0.4, 0.7, 0.3])
b = 0.1

z = np.dot(x, w) + b
output = 1 / (1 + np.exp(-z))

print("Weighted sum:", z)
print("Neuron output:", output)
Useful for understanding the mathematical connection between inputs, weights, bias and activation.

PyTorch · Classification Model

Implementation
import torch
import torch.nn as nn

class Classifier(nn.Module):
    def __init__(self, n_features, n_classes):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_features, 32),
            nn.ReLU(),
            nn.Linear(32, n_classes)
        )

    def forward(self, x):
        return self.net(x)

model = Classifier(4, 3)
print(model)
This structure can be extended with a Dataset, DataLoader, loss function, optimiser and training loop.

PyTorch · CNN Skeleton

Computer Vision
import torch.nn as nn

class CNN(nn.Module):
    def __init__(self, classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        self.classifier = nn.Linear(64 * 8 * 8, classes)

    def forward(self, x):
        x = self.features(x)
        x = x.flatten(1)
        return self.classifier(x)
For CIFAR-10, a 32×32 input becomes 8×8 after two 2×2 pooling operations.
