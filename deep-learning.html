Overview

Deep Learning Learning Path

The subject is organised as modules and numbered topics. Hours, L/T/P information and formal unit tables are intentionally omitted.

Deep learning uses multilayer neural networks to learn representations directly from data. This page follows a progressive path from fundamental neural-network concepts to CNNs, sequence models, generative learning and real-world computer-vision applications. Each topic can later be connected to detailed notes, mathematical explanations, diagrams, Python examples, PyTorch notebooks, practical exercises and references.
